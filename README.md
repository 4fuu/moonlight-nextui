# moonlight-nextui

Moonlight game streaming adapted for NextUI on TrimUI Brick Pro / tg5040.

Rebuilt Apostrophe wrapper (fork of richieszemeredi/nextui-moonlight-pak) +
[nextui-app-sdk](https://github.com/4fuu/nextui-app-sdk) cooperation (in-process
HOME overlay in menu mode, sleep/wake handshake, volume/brightness HUD, battery)
+ bundled spruce moonlight-embedded engine. Self-built via the tg5040 toolchain.

Integration plan: https://ampcode.com/artifacts/moonlight-sdk-e0e0c7bc-58f6-46d7-9bcd-6e31a08e7a96

Status: infrastructure build-out in progress.
